REBORN LAUNCHER
An unofficial launcher and test server, compatible with the Ashes of Creation game client.

HOW TO PLAY

You need your own Ashes of Creation installed through Steam, the build of 2026-01-29. This pack contains no game files.

1. Close the game if it is open, and unzip this folder anywhere.
2. Double-click "Start Reborn Launcher.bat".
3. The first time, Windows warns about adding the "Reborn Launcher CA" certificate. Choose Yes, or the game cannot connect.
4. In the launcher, type a NEW username and password in the two boxes and press Register.
   Username: 3-32 letters, numbers, . _ or -   Password: at least 4 characters.
   Do not reuse a password from anywhere else. Next time, press Login instead.
5. If the launcher cannot find your game, use Auto-Detect or Browse. Then press LAUNCH GAME.

GOOD TO KNOW

- This is an unofficial test server. It may be restarted or wiped, or go away, at any time.
- It is not made by, or connected with, Intrepid Studios. Ashes of Creation is their trademark, named here only to say
  which game client this works with. Using this may be against the game's terms; that choice is yours.
- It starts the game without its usual online services, and possibly without its anti-cheat.
- The certificate you trust stays in Windows until you remove it: run certmgr.msc, open Trusted Root Certification
  Authorities, Certificates, and delete "Reborn Launcher CA".
